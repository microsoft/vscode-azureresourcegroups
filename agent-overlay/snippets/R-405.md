## Budget Tiers

> ⛔ **Free/shared tiers (App Service F1/D1, Static Web Apps Free) are NOT offered.** Every app requires a managed identity for Azure resource auth, and the free-tier MI sidecar OOMs on Linux; free SWA also lacks the CORS and custom-auth configuration these apps need. The compute floor is **B1 (App Service)** / **Standard (Static Web Apps)**. Never emit F1, D1, or Free.
>
> ⛔ **Functions floor is Flex Consumption — NOT Consumption or Elastic Premium.** Consumption and Elastic Premium back `AzureWebJobsStorage` with Azure Files, which does not support managed-identity connections and therefore requires `allowSharedKeyAccess` on the storage account — banned by the managed-identity-only rule. Flex Consumption supports identity-based `AzureWebJobsStorage`, so it is the only Functions plan compatible with `allowSharedKeyAccess: false`. This is the same floor-raise as App Service F1 → B1.

| Service | Cost-optimized | Balanced | Production |
|---|---|---|---|
| App Service | B1 (Basic) | B1 / S1 | P1v3 |
| Static Web Apps | Standard | Standard | Standard |
| Functions | Flex Consumption | Flex Consumption | Premium EP1 |
| PostgreSQL / MySQL | Standard_B1ms (Burstable) | Standard_B1ms | Standard_D2ds_v4 |
| Redis | Basic C0 | Standard C1 | Premium P1 |
| Container Apps | Consumption | Consumption | Dedicated |

> ⚠️ **Log Analytics `Free` SKU is deprecated.** ARM rejects it with some API versions and retention settings. Always use `PerGB2018` — the first 5 GB/month is free anyway.

⛔ **There is no $0 tier.** Any app with a compute component has a non-zero monthly cost and MUST get a live pricing call. If the floor SKU is unavailable during deploy prep (no B1 quota), fall back to the cheapest **available** tier at or above the floor and record an `assumptions[]` note stating why, so the approval gate presents the resulting cost.
